Act 1

第一幕：用基础规则检查第一周

字段定义

ai_cost_yuan 是周度运营成本，hours_saved 是估算节省工时，不等于已实现收入。

数据质量

data_completeness_pct 反映报告完整度；agent_rework_count 是交付前因数据或验证问题触发的自动返工次数。

审批与风险

approval_status 是输入检查；Bug 重开率会在第二幕升级为硬门槛。

v1.0 规则：ai_cost_yuan <= 8000、data_completeness_pct >= 90、agent_rework_count <= 2、approval_status == approved。

完成以下任务：
